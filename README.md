# 🧑‍🦯 YOLO-World 기반 시각장애인 보행 보조 시스템

**Open-Vocabulary AI Object Detection & Embedded Audio Optimization for Visually Impaired Navigation**

본 프로젝트는 라즈베리파이 환경에서 **YOLO-World**를 활용하여 시각장애인의 안전한 실내외 보행을 돕는 **웨어러블 하드웨어 보조 기기**입니다. 제한된 하드웨어 자원의 한계를 극복하기 위해 멀티스레딩 및 하이브리드 로컬 사운드 가속 아키텍처를 적용했습니다.

---

## 🎯 1. 주요 목적 및 핵심 기능

* **오픈 보카블러리(Open-Vocabulary) 보행 환경 인식:** 볼라드, 라바콘, 물웅덩이, 계단, 문 손잡이 등 시각장애인의 보행을 위협하거나 이동에 필수적인 다양한 객체를 실시간으로 탐지합니다.
* **실내/외(Indoor/Outdoor) 컨텍스트 스위칭:** 주변 사물(냉장고, 침대 vs 자동차, 가로수 등)의 배치 힌트를 AI가 스스로 분석하여 현재 보행 환경이 실내인지 실외인지 판별하고, 해당 환경에 맞는 탐지 가중치를 실시간으로 튜닝합니다.
* **물리 인터페이스 기반 제어:** 하드웨어 버튼(GPIO 3번 핀)을 통해 디스플레이가 없는 환경에서도 기기 종료, 탐지 시작/일시 정지를 직관적으로 제어합니다.

---

## 💡 2. 본 제품만의 차별점 (Core Strengths)

* **골전도 디바이스를 통한 보행 안전 확보:** 귀를 막지 않는 골전도 오디오 방식을 채택하여, AI 안내 음성을 들으면서도 자동차 경적 소리, 주변 보행자 음성 등 외부 환경 소리를 100% 동시 청취할 수 있어 실제 보행 안전성을 극대화했습니다.
* **100% 완전한 오프라인 구동 (네트워크 독립성):** 야외, 지하, 대중교통 등 와이파이나 LTE 데이터 연결이 불가능한 실제 보행 환경에서도 통신 음영 지역 없이 무결점으로 구동됩니다.
* **제로 레이턴시(0ms 수준) 오디오 스트리밍:** AI가 위험 객체를 감지하는 즉시 RAM 주소에서 사운드 카드로 데이터를 다이렉트 슛하는 구조를 채택하여 안내 레이턴시를 최소화했습니다.
* **동기식 블로킹(Blocking) 결함 완치:** 안내 음성이 나오는 1~2초 동안 AI 카메라 연산 및 객체 탐지가 일시 정지되는 기존 임베디드 오디오의 한계를 멀티스레드 격리 구조로 완벽히 해결했습니다.
* **자연스러운 한국어 발음 및 고속 안내:** 조악한 오픈소스 기계음 대신 구글 gTTS 기반 고품질 음성을 사용하되, `SoX` 인코더를 통해 1.4배속 고속 발화(`tempo 1.4`)로 전처리하여 실시간 장애물 회피 능력을 극대화했습니다.

## 🏗️ 3. 하드웨어 가속 및 음성 런타임 구조

라즈베리파이의 성능을 극한으로 끌어올리기 위해 **[gTTS 사전 캐싱] ➡️ [SoX 배속 변환] ➡️ [Pygame RAM 상주]** 기술 융합 아키텍처를 직접 설계했습니다.

```
[초기화 단계: 최초 1회]
구글 서버 (gTTS 문장 합성) ➡️ SoX (1.4배속 인코딩) ➡️ 로컬 MP3 생성 
                                                         │
[부팅 단계: 기기 Launch]                                   ▼
로컬 MP3 파일 ➡️ pygame.mixer.Sound 로드 ➡️ 라즈베리파이 RAM (AUDIO_BANK C-포인터 상주)

[런타임 단계: 실시간 보행]
AI 장애물 감지 ➡️ 디스크 I/O 없이 RAM 주소에서 사운드 카드로 다이렉트 스트리밍 (0.001초)

```

## 🎯 6. 결론 (Conclusion)

본 시스템은 수백만 원을 호가하는 기존의 상용 시각장애인 스마트 글래스나 전용 보조 장비 대비, **약 20만 원 대의 보편적인 오픈소스 임베디드 부품 구성**만으로 고성능 AI 보행 보조 시스템을 구축할 수 있음을 증명했습니다.

특히 주변 환경 소리를 차단하지 않는 **골전도 방식의 안전 최적화 설계**와 하드웨어 자원이 열악한 환경에서 발생하는 오디오 병목 문제를 **로컬 RAM 뱅크 주소 다이렉트 스트리밍 기법**으로 극복함으로써, 저비용·오프라인 구동·사용자 안전성이라는 세 가지 핵심 가치를 완벽하게 만족하는 혁신적인 임베디드 소프트웨어 솔루션입니다.
