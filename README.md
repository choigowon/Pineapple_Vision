# 🧑‍🦯 YOLOE 기반 시각장애인 보행 보조 시스템

**YOLOE-Based Walking Assistance System for the Visually Impaired**

카메라 영상에서 주변의 장애물과 주요 시설물을 인식하고, 음성 안내를 통해 시각장애인의 보행을 보조하는 시스템입니다. YOLOE 기반 객체 인식과 문, 손잡이, 계단 및 횡단보도 주변 상황에 대한 정보를 제공합니다.

---

## 🎯 프로젝트 소개

시각장애인은 보행 중 장애물, 출입문, 계단 및 횡단보도 주변 상황을 파악하는 데 어려움을 겪을 수 있습니다.
본 프로젝트는 카메라 영상에서 주변 환경을 인식하고, 중요한 정보를 음성으로 전달하여 사용자가 주변 상황을 파악하는 데 도움을 주는 것을 목표로 합니다.

주요 설계 목표는 다음과 같습니다.
- 주변 객체를 인식하고 보행에 필요한 정보를 제공
- 객체의 화면상 위치를 기반으로 방향 안내
- 문 손잡이 종류와 문 안내 문구를 인식
- 횡단보도 주변의 차량 관련 객체를 감지하여 주의 안내
- 불필요한 음성 안내를 줄이고 긴급 안내를 우선 처리

---

## ✨ 주요 기능

### 1. YOLOE 기반 객체 인식
- 카메라 영상에서 보행에 필요한 객체를 탐지합니다.
- 객체 종류에 따라 서로 다른 신뢰도 기준을 적용합니다.
- 객체의 위치와 크기를 분석하여 안내 대상을 선정합니다.

### 2. 장애물 위치 및 방향 안내
- 객체가 화면의 왼쪽, 중앙 또는 오른쪽 어디에 위치하는지 분석하여 방향 정보를 제공합니다.
- 연속 프레임에서 객체가 확인되는지 검사하여 순간적인 오인식으로 인한 안내 변화를 줄입니다.

> **참고:** 화면상 위치를 이용한 판단이며, 실제 거리나 충돌 가능성을 정확하게 측정하는 기능은 아닙니다.

### 3. 문 손잡이 인식 및 OCR
- 문 손잡이 유형을 구분하고, 지원되는 객체 유형에 따라 밀기·당기기 등의 행동 정보를 안내합니다.
- OCR(광학 문자 인식)을 활용하여 문에 표시된 '미세요', '당기세요' 등의 문구를 인식합니다.
- 반복 안내를 줄이기 위한 처리 로직을 적용합니다.

### 4. 계단 및 엘리베이터 인식
- 계단 및 엘리베이터 관련 객체를 탐지합니다.
- 일정 프레임 동안 검출 결과를 확인한 후 안내하여 순간적인 오검출의 영향을 줄입니다.

### 5. 횡단보도 모드
- 횡단보도 관련 객체가 지속적으로 검출되면 횡단보도 모드로 전환합니다.
- 화면상 위치를 확인하여 횡단보도의 정렬 상태를 안내합니다.
- 차량 관련 객체가 검출되면 정지 등의 주의 안내를 우선합니다.

현재 판단 로직은 영상의 객체 검출 결과와 화면상 위치, 일정 시간 동안의 검출 상태에 기반합니다. 실제 차량 속도와 거리, 신호등 상태 또는 도로 전체의 안전 여부를 완벽하게 판단하지는 못합니다.

### 6. 음성 안내 우선순위 처리
- 여러 안내가 동시에 발생할 때 중요한 안내를 우선 처리합니다.
- 긴급 안내 발생 시 대기 중인 음성을 정리하거나 진행 중인 음성의 취소를 요청합니다.
- 반복 안내를 줄여 사용자가 필요한 정보를 파악하기 쉽도록 구성합니다.

## ⚙️ 시스템 동작 방식

```
카메라 영상 입력
       ↓
YOLOE 객체 탐지
       ↓
객체 종류 · 위치 · 크기 분석
       ↓
연속 프레임 확인 및 안내 대상 선정
       ↓
 ┌──────────┬──────────┐
 │ 일반 보행 │ 횡단보도  │
 │ 장애물 안내│ 차량 주의 │
 │ 문·계단   │ 위치 확인 │
 └──────────┴──────────┘
       ↓
OCR 및 음성 안내 처리
       ↓
음향 출력 장치

```

## ⚠️ 한계 및 주의사항

교통 안전 판단의 한계: 차량의 실제 속도, 거리, 신호 상태 및 도로 전체의 위험을 완벽하게 판단하지 못합니다.

인식 오류 가능성: 조명, 가림, 카메라 흔들림 및 학습 데이터에 따라 오검출이나 미검출이 발생할 수 있습니다.

하드웨어 연동 확인 필요: 초음파 센서와 음향기기의 실제 연결 상태는 하드웨어 시험을 통해 확인해야 합니다.

실외 사용 검증 필요: 실제 보행 환경에서 충분한 안전성 검증을 완료하기 전에는 안전한 이동을 보장할 수 없습니다.
